1. Создайте виртуальное окружение и активируйте его:
  
   Для macOS/Linux
   ```bash
   python3 -m venv venv
   source venv/bin/activate 
   ```
   Для Windows
   ```bash
   python -m venv myenv
   myenv\Scripts\activate
   ```
   
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Выполнить скрипт по подсчету данных командой:
   ```bash
   python calculate_stock.py    
   ```
